= NetApp Workload Factoryから認証情報を削除する
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
認証情報が不要になった場合は、Workload Factoryから削除できます。FSx for ONTAPファイルシステムに関連付けられていない認証情報のみを削除できます。

.手順
. link:https://console.netapp.com["NetApp Console"^]にログインします。
. NetApp Consoleメニューから、*ワークロード* > *管理* > *認証情報*を選択します。
. 「認証情報」ページで、以下の操作を行います：
+
** Workload Factoryコンソールで、認証情報のセットのアクションメニューを選択し、*削除*を選択します。確認のために*削除*を選択します。
** NetApp Consoleで、一連の認証情報のアクションメニューを選択し、*削除*を選択します。確認のために*削除*を選択します。
