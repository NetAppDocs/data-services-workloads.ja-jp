= NetApp Workload Factory のリソースのコストを追跡してレポートを取得する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp Workload Factory は、FSx for ONTAP ファイルシステムのコストと使用状況の統合ビューを提供し、予算管理とリソースの効率的な最適化を支援します。FSx for ONTAP ファイルシステムリソースのコストレポートを生成して、関係者と共有することもできます。



[[about-this-task]]
== タスク概要

Workload Factory は、AWS Cost Explorer からコストデータを取得することで、FSx for ONTAP ファイルシステムのコストと使用状況を追跡します。以下のコスト詳細が追跡されます：使用タイプ、使用 SKU、デプロイメントタイプ、使用量、および合計コスト。

固有のリソースの場合、Workload Factory は、実際のパフォーマンスティアの使用状況、プロビジョニング済みだが未使用のスペースに割り当てられたパフォーマンスティアコストの比例配分、容量ごとに分配されたパフォーマンス割り当て、および容量プールの使用状況を組み合わせてコストを計算します。Workload Factory は、各コンポーネントにそのディメンションにおける単価を乗算し、その結果を合計して各リソースの総コストを決定します。

コストダッシュボードでは、AWSアカウント、認証情報、1つ以上のリージョン、および時間範囲でコストと使用状況データをフィルタリングして、FSx for ONTAPファイルシステムの使用量を把握できます。Workload Factoryは常に月単位でデータを表示します。1つ以上のファイルシステム、およびファイルシステム内の1つ以上のボリュームでフィルタリングすることもできます。AWSのコスト配分タグキーとタグキー値は、特定のコストを特定するための追加のフィルタリングレイヤーを提供します。_タグ_はキーと値で構成されます。タグキーとタグキー値でフィルタリングするには、FSx for ONTAPファイルシステムにタグを割り当てます。link:https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/cost-alloc-tags.html["AWSのコスト配分タグについて詳しくはこちらをご覧ください。"^]

Workload Factory は、以下の権限を使用して AWS Cost Explorer から FSx for ONTAP ファイルシステムリソースのコストと使用状況データを取得します： `ce:GetCostAndUsage` および  `ce:GetTags`。総コストは、AWS コスト API と当社独自の見積もりを使用して算出します。

コストダッシュボードのコストデータに加えて、コストエグゼクティブサマリーには、FSx for ONTAP ファイルシステムのコストと組織の支出パターンが表示されます。FSx for ONTAP ファイルシステムリソースのコストレポートを生成することもできます。このレポートはダウンロード可能な CSV ファイルで、関係者と共有できます。



[[track-costs]]
== コストを追跡する

Workload Factory コンソールのコストダッシュボードに表示されるコストは、AWS Cost Explorer のデータに基づいており、24時間ごとに更新されます。

.開始する前に
以下の要件を満たしていることを確認してください。

* Workload Factory で FSx for ONTAP のコストを追跡するには、link:add-credentials.html["_表示、計画、分析_権限ポリシーで認証情報を付与する"^]必要があります。
* AWS割り当てタグでフィルタリングするには、FSx for ONTAPファイルシステムにタグが割り当てられていることを確認してください。


.手順
. link:https://console.netapp.com["NetApp Console"^]にログインします。
. メニューimage:workloads-menu-icon.png["ハンバーガーメニューアイコンは、Workload Factoryのメニュー項目であるWorkloadsに移動するために使用します"]、*ワークロード* > *ストレージ* > *FSx for ONTAP* を選択します。
. *FSx for ONTAP* メニューから、*コスト* を選択します。
. コストダッシュボードから、以下の情報を指定して FSx for ONTAP リソースのコストと容量データをフィルタリングします。
+
.. *AWSアカウント*：コストデータを表示するアカウントを選択します。
.. *認証情報*：_表示、計画、および分析_の権限を持つ認証情報を選択してください。
.. *リージョン*：コストデータを表示するAWSリージョンを選択してください。
.. *コストデータ範囲*：表示するコストデータの期間を選択してください。
.. *割り当てタグキー*：（オプション）割り当てタグキーとその値を選択して、AWS タグに関連付けられたすべての FSx for ONTAP ファイルシステムの詳細なコストレポートを生成します。
.. *割り当てタグ値*：（オプション）割り当てタグキーに関連付けられた割り当てタグキー値を選択して、AWS タグに関連付けられたすべての FSx for ONTAP ファイルシステムの詳細なコストレポートを生成します。


. FSx for ONTAPリソースの*コスト詳細*を表示します。




[[generate-cost-reports-for-your-fsx-for-ontap-resources]]
== FSx for ONTAP リソースのコストレポートを生成する

特定の FSx for ONTAP ファイルシステムリソースのコストレポートを生成し、関係者と共有します。

.手順
. コストダッシュボードで、*レポートの生成*を選択します。
. レポート画面で、以下の情報を入力してください。
+
.. *ファイルシステム*：レポートに含める FSx for ONTAP ファイルシステムを1つ以上選択してください。
.. *ボリューム*：（オプション）レポートに含めるボリュームを1つ以上選択します。




.結果
CSV形式のレポートが生成され、ダウンロードできます。
