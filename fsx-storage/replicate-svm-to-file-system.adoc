= ストレージVMを別のFSx for ONTAPファイルシステムに複製する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp Workload FactoryでストレージVMを別のFSx for ONTAPファイルシステムにレプリケートすると、データ損失が発生した場合に備えてデータアクセスの保護レイヤが提供されます。この操作により、1つのストレージVM内のすべてのボリュームが別のFSx for ONTAPファイルシステムにレプリケートされます。

.開始する前に
ストレージ VM を別の FSx for ONTAP ファイルシステムにレプリケートするには、リンクを関連付ける必要があります。link:create-link.html["既存のリンクを関連付ける方法、または新しいリンクを作成して関連付ける方法を学びます"^]。リンクを関連付けたら、この操作に戻ってください。

.手順
. link:https://console.netapp.com["NetApp Console"^]にログインします。
. メニューimage:workloads-menu-icon.png["ハンバーガーメニューアイコンは、Workload Factoryのメニュー項目であるWorkloadsに移動するために使用します"]、*ワークロード* > *ストレージ* > *FSx for ONTAP* を選択します。
. *FSx for ONTAP*から、レプリケートするストレージVMを含むファイルシステムのアクションメニューを選択し、*管理*を選択します。
. ファイルシステムの概要で、Storage VMの下にある*管理*を選択します。
. ストレージ VM の管理画面で、複製するストレージ VM のアクションメニューを選択し、*高度なアクション* > *ストレージ VM の複製* を選択します。
. 「データの複製」ページで、「複製ターゲット」の下に、以下を指定します：
+
.. *FSx for ONTAP ファイル システム*：ターゲット FSx for ONTAP ファイル システムのクレデンシャル、リージョン、および FSx for ONTAP ファイル システム名を選択します。
.. *ストレージVM名*：ドロップダウンメニューからストレージVMを選択してください。
.. *ボリューム名*：ターゲットボリューム名は、 `{OriginalVolumeName}_copy`の形式で自動的に生成されます。
.. *階層化ポリシー*：ターゲットボリュームに保存されるデータの階層化ポリシーを選択します。
+
Workload Factoryコンソールでボリュームを作成する場合、デフォルトの階層化ポリシーは_Auto_です。ボリューム階層化ポリシーの詳細については、Amazon FSx for NetApp ONTAPドキュメントのlink:https://docs.aws.amazon.com/fsx/latest/ONTAPGuide/volume-storage-capacity.html#data-tiering-policy["ボリュームストレージ容量"^]を参照してください。

.. *最大転送速度*：*制限付き*を選択し、最大転送制限をMB/sで入力します。または、*無制限*を選択します。
+
制限がない場合、ネットワークとアプリケーションのパフォーマンスが低下する可能性があります。ただし、主に災害復旧に使用されるような重要なワークロードのFSx for ONTAPファイルシステムには、無制限の転送速度を推奨します。



. レプリケーション設定で、以下の情報を入力してください：
+
.. *レプリケーション間隔*：ソースボリュームからターゲットボリュームにスナップショットを転送する頻度を選択します。
.. *長期保存*：オプションで、長期保存用のスナップショットを有効にします。
+
長期保持を有効にする場合は、既存のポリシーを選択するか、新しいポリシーを作成して、複製するスナップショットと保持する数を定義します。

+
... 「既存のポリシーを選択」では、ドロップダウンメニューから既存のポリシーを選択してください。
... *新しいポリシーを作成する* には、以下の情報を入力してください：
+
.... *ポリシー名*：ポリシー名を入力してください。
.... *スナップショットポリシー*：表で、スナップショットポリシーの頻度と保持するコピーの数を選択します。スナップショットポリシーは複数選択できます。






. 「作成」を選択します。


.結果
ストレージVM内のすべてのボリュームは、ターゲットファイルシステムに複製されます。
