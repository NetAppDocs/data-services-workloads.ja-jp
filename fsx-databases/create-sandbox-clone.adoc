= データベース向けNetApp Workload Factoryでサンドボックスクローンを作成する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp Workload Factory for Databasesでデータベースのサンドボックスクローンを作成すると、ソースデータベースを変更することなく、開発、テスト、統合、分析、トレーニング、QAなどにクローンを使用できます。

.タスク概要
サンドボックスクローンは、ソースデータベースの最新のスナップショットから作成されます。ソースデータベースと同じMicrosoft SQL Serverにクローンすることも、同じFSx for ONTAPファイルシステムを共有している限り、別のMicrosoft SQL Serverにクローンすることもできます。

.開始する前に
サンドボックスクローンを作成する前に、以下の前提条件をすべて満たしていることを確認してください。

* *認証情報と権限*：Workload Factory でサンドボックスクローンを作成するには、link:../fsx-storage/add-credentials.html["AWSアカウントの認証情報と_操作および修復_権限"^]が必要です。
+
あるいは、Codeboxを使用して、部分的に完成したテンプレートをコピーするか、完成したテンプレートを作成することで、REST APIを使用してWorkload Factoryの外部でサンドボックスクローンを作成できます。link:../admin/codebox-automation.html["Codeboxによる自動化について詳しくはこちらをご覧ください"^]。

* *Microsoft SQL Server*：新しいサンドボックスクローンをホストするには、データベース向けWorkload Factoryに管理対象のMicrosoft SQL Serverが必要です。
* *AWS Systems Manager*：AWS Systems Managerを介してMicrosoft SQLホストで `NT Authority\SYSTEM`ユーザ権限が有効になっていることを確認します。
* *ソースデータベース*：クローンにはソースデータベースが必要です。


.手順
. link:https://console.netapp.com["NetApp Console"^]にログインします。
. メニュー image:workloads-menu-icon.png["ハンバーガーメニューアイコンは、Workload Factoryのメニュー項目であるWorkloadsに移動するために使用します"] から、*ワークロード* > *データベース* を選択します。
. データベースで、*サンドボックス*タブを選択します。
. 「サンドボックス」タブで、「新しいサンドボックスを作成」を選択します。
. 「新しいサンドボックスの作成」ページで、「データベースソース」に以下を入力します：
+
.. *ソースデータベースホスト*：ソースデータベースホストを選択してください。
.. *ソースデータベースインスタンス*：ソースデータベースインスタンスを選択します。
.. *ソースデータベース*：クローン元のソースデータベースを選択してください。


. 「データベースターゲット」には、以下を指定してください：
+
.. *ターゲットデータベースホスト*：ソースホストと同じVPC内にあり、同じFSx for ONTAPファイルシステムを持つ、サンドボックスクローン用のターゲットデータベースホストを選択します。
.. *対象データベースインスタンス*：サンドボックスクローンの対象データベースインスタンスを選択します。
.. *対象データベース*：サンドボックスクローンの名前を入力してください。


. *マウント*：複数のデータ ファイルやログ ファイルを含む SQL データベースをクローンする場合、Workload Factory は自動割り当てまたは定義されたドライブ文字の下にあるすべてのファイルをクローンします。
+
次のいずれかのオプションを選択します。

+
.. *マウントポイントの自動割り当て*
.. *マウントポイントのパスを定義する*
+
マウントポイントのパスを定義するには、以下を指定してください：

+
*** データ ファイル パスのドライブ文字を入力してください。
*** ログファイルのパスを示すドライブ文字を入力してください。




. *タグの定義*：サンドボックスクローンを定義するタグを選択してください。
. *作成*をクリックします。


ジョブの進捗状況を確認するには、「ジョブ監視」タブに移動してください。
