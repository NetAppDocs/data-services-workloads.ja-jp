= Google Cloud NetApp Volumes のクイックスタート
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Google Cloud を設定してからシステムを作成して、Google Cloud NetApp Volumes の使用を開始します。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"] link:set-up.html["Google Cloud NetApp Volumes のセットアップ"]
[role="quick-margin-para"]
Googleでサービスアカウントを作成してください。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["2"] link:add-roles.html["役割を割り当てる"]
[role="quick-margin-para"]
Google Cloud NetApp Volumes の利用を開始するには、適切な権限と、Google Cloud NetApp Volumes 管理者または Google Cloud NetApp 閲覧者のロールが割り当てられている必要があります。

[role="quick-margin-para"]
image:role_gcnv.png["Google Cloud NetApp Volumes ロールのスクリーンショット。"]

[role="quick-margin-para"]
NetApp Consoleから、メンバーに適切なロールを割り当てます。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["3つ"] link:create-discover-systems.html["システムを追加する"]
[role="quick-margin-para"]
NetApp Consoleから、*システムの追加*、*Google Cloud Platform*、*Google Cloud NetApp Volumes*、*Discover*の順にクリックします。サービスアカウントとGoogle Cloudプロジェクトの詳細を指定します。
